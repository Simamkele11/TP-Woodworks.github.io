TP WOODWORKS — WEBSITE CONCEPT
================================

This is an independent demo concept, not an official TP Woodworks website.

FILES
- index.html: page structure and content
- styles.css: layout, colours, responsive styles
- script.js: mobile navigation and demo form behaviour

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension in VS Code.

BEFORE SHARING
- Check every section on mobile and desktop.
- Confirm business services and claims with TP Woodworks.
- Replace stock/design-reference photos with their own photos only with permission.
- Replace the demo form with a real enquiry channel only after confirming their preferred contact details.
- Do not present the demo as their official website. The concept notice is intentionally visible.

FREE HOSTING
You can publish this static site with GitHub Pages or Netlify. You will need to create/sign in to your own account and upload/push these files. The site uses external Google Fonts and Unsplash-hosted images, so those need an internet connection.
